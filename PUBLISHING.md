# Порядок публикации Zlatopil Alert

Этот документ фиксирует целевую схему канала обновлений. Фактические пакеты и манифесты появятся только после подготовки и проверки глобальной версии 0.5.0.

## Структура канала

В ветке `main` будут храниться два отдельных стабильных манифеста:

- `stable/win7/manifest.json` — обновления для Windows 7 SP1.
- `stable/win10/manifest.json` — обновления для Windows 10.

Планируемые публичные HTTPS-адреса:

- `https://raw.githubusercontent.com/usznuas/zlatopil-alert-updates/main/stable/win7/manifest.json`
- `https://raw.githubusercontent.com/usznuas/zlatopil-alert-updates/main/stable/win10/manifest.json`

Приложение должно выбирать адрес в соответствии со своей сборкой/целевой ОС. Манифест содержит версию, HTTPS-ссылку на пакет, SHA-256, подпись и примечания к выпуску.

## Публикация релиза

Планируемый тег первого глобального выпуска: `v0.5.0`.

В GitHub Release будут приложены два отдельных архива (точные имена будут закреплены после финальной сборки):

- пакет Native 0.5.0 для Windows 7 SP1;
- пакет Native 0.5.0 для Windows 10.

После загрузки архивов создаются отдельные подписанные манифесты, каждый указывает на свой пакет и его SHA-256. Сначала проверяется тестовая установка и откат; только после этого манифесты публикуются по стабильным адресам.

## Подписание

Для подписи используется подготовленный скрипт `Sign-ReleaseManifest.ps1` и закрытый RSA-3072 ключ владельца релиза.

Закрытый ключ:
- хранится у владельца офлайн, желательно на зашифрованном носителе и с отдельной резервной копией;
- не загружается в этот репозиторий, GitHub Releases, исходники или пакеты программы;
- не отправляется в чаты и не включается в диагностические отчёты.

Открытый ключ уже закреплён в исходном коде Native 0.4.1/0.4.2/0.4.3. До реализации 0.5.0 его соответствие закрытому ключу следует проверить тестовой подписью на локальном компьютере.

## Текущий статус

Сейчас создан публичный репозиторий и опубликованы README/правила безопасности. Настоящие пакеты, манифесты и релиз ещё не создавались. Промежуточные версии не публикуются: первый планируемый стабильный выпуск — глобальная версия 0.5.0.
