# Zlatopil Alert — канал обновлений

Этот публичный репозиторий используется **только для распространения подписанных обновлений** Zlatopil Alert.

Исходный код приложения, пользовательские настройки и секреты здесь не размещаются.

## Назначение

Приложение обращается к этому репозиторию по HTTPS, проверяет сведения о выпусках и загружает подходящий пакет для своей системы.

Поддерживаемые ветви распространения:
- Windows 7 SP1 — отдельный совместимый пакет.
- Windows 10 — отдельный пакет.

## Правила публикации

Каждый стабильный выпуск должен содержать:
1. Пакет обновления для соответствующей Windows.
2. SHA-256 каждого пакета.
3. Цифровую подпись манифеста, проверяемую открытым ключом, встроенным в приложение.
4. Описание изменений и известные ограничения.

Публикация считается готовой только после проверки подписи, хеша, совместимости и сценария отката.

## Защита

- Закрытый ключ подписи хранится отдельно от GitHub и никогда не публикуется.
- В репозиторий нельзя загружать API-токены, ключи Azure, пароли, пользовательские логи и приватные данные.
- Обычные тестовые сборки не публикуются как стабильные обновления.
- Пакеты для Windows 7 и Windows 10 не смешиваются.

## Планируемые материалы релиза

Фактические имена файлов и формат манифеста будут закреплены вместе с реализацией механизма обновления в Zlatopil Alert Native 0.5.0. До этого момента здесь не публикуются фиктивные манифесты или пакеты.
